# TrainexAI Health Agent Build Task

Build a separate hackathon MVP for TrainexAI Health Agent.

This project must not depend on the main production TrainexAI app.

Product sentence:
TrainexAI Health Agent helps users convert daily fitness, food, sleep, water, and mood check-ins into one safe, practical action plan for the day.

Core features:
1. Landing page
2. Health profile setup
3. Daily check-in form
4. AI daily action card
5. Weekly health summary
6. Safety disclaimer
7. Clean demo flow for judges
8. Professional TrainexAI branding

Suggested stack:
- Frontend: Next.js or React
- Backend: FastAPI or API routes
- Database: Supabase/Postgres
- AI: Gemini, OpenRouter, or Groq through environment variables only

Rules:
- Do not hardcode API keys.
- Do not make medical diagnosis claims.
- Do not copy production TrainexAI backend/admin/payment/internal operations code.
- Keep the MVP simple, professional, and demo-ready.
