# TrainexAI Startup Context

TrainexAI is a fitness and health startup focused on practical daily guidance.

The main product helps users with fitness, workout planning, nutrition direction, progress tracking, AI coaching, and personal health improvement.

For this hackathon, we are building a separate product called TrainexAI Health Agent.

TrainexAI Health Agent should feel like a safe daily decision engine:
- User enters daily check-in data.
- The system understands today's body state.
- AI gives one practical action plan for the day.
- The plan includes movement, food, water, sleep, recovery, and habit guidance.

This is not a medical diagnosis tool.
This is not a hospital product.
This is a fitness and wellness decision assistant.

Tone:
Professional, human, calm, useful, and trustworthy.
