# TrainexAI Brand Guide

Use the copied logo files from:

frontend/public/logo.svg
frontend/public/logo-mark.svg

Brand style:
- Professional
- Clean
- Trustworthy
- Health and fitness focused
- Startup-ready

Colors:
- Primary navy: #17324D
- Deep text: #0F172A
- Accent orange: #F59E0B
- Background: #F7F5F0
- White card: #FFFFFF
- Border: #E5E7EB
- Muted text: #64748B
- Success: #059669
- Warning: #D97706
- Error: #DC2626

Typography:
Use Inter or system sans-serif.

Avoid:
- Generic AI-looking text
- Too many gradients
- Medical hospital-style design
- Fake metrics
- Overpromising health results
